# Media

This folder contains the visual documentation and design files related to the **Energy-Efficient Path Planning for Mobile Robots using Genetic Algorithms** project.

## Folder Structure

```text
Media/
│
├── Robot_Photos/
│   ├── Photos of the two-wheel differential-drive mobile robot
│   └── Robot design and related files
│
├── Robot_Videos/
│   └── Videos demonstrating the working of the mobile robot
│
└── Dashboard_Screenshots/
    └── Screenshots of the ESP32-based web control and monitoring dashboard
```

## Robot Photos

The `Robot_Photos` folder contains photographs of the developed two-wheel mobile robot, including its physical structure, hardware setup, and available robot design files.

📁 [Open Robot Photos](./Robot_Photos)

## Robot Videos

The `Robot_Videos` folder contains videos demonstrating the working and movement of the developed mobile robot.

📁 [Open Robot Videos](./Robot_Videos)

## Dashboard Screenshots

The `Dashboard_Screenshots` folder contains screenshots of the ESP32-based web dashboard used for:

* Manual robot control
* Encoder monitoring
* Distance-based movement
* Turning control
* Shape navigation
* Line following
* IMU monitoring
* Sensor monitoring
* Data recording and report generation

📁 [Open Dashboard Screenshots](./Dashboard_Screenshots)

---

> **Note:** Media related to the independent YDLIDAR X2, ROS 2, and RViz2 experiments is maintained separately in the [`LiDAR_ROS2/Media`](../LiDAR_ROS2/Media) folder.
